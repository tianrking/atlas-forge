# AI Supply Chain Lab

一个用 React + vinext 实现的可交互 AI 基础设施产业链地图：从“大语言模型能力提升”开始，点击节点逐层下钻，最多看到 L5 深度的上游设备、材料、封装、连接和基础设施企业。

## 页面能力

- 六层结构：模型需求、能力驱动、资源瓶颈、一级企业、二级上游、L5 深处。
- 点击企业或资源节点后，右侧检查器会显示市场属性、产业链角色、需求弹性、研究逻辑、下一层节点和公开资料链接。
- 右侧 `+ / −` 控制树展开；“展开当前子树”可以一次打开当前节点下面的全部路径。
- 搜索公司、股票代码、技术或上游环节；筛选一级直接、高弹性、上游设备、放大区间和美股可交易节点。
- 三种情景：更大模型、长思考 + Agent、算法效率提升。资源倍数是敏感度区间，不是公司收入或股价预测。
- 已预置 GPU / AI ASIC、HBM、先进封装、CPU / CXL、SSD、交换机、800G / 1.6T / CPO、硅光、CW 光源、服务器、电力和液冷等产业链分支。

## 本地运行

要求 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000/`。

## 验证

```bash
npm run lint
npm test
```

`npm test` 会先执行生产构建，再验证服务端 HTML、五层树结构、主要美股代码和交互数据是否仍然存在。

## 数据边界

页面中的企业、股票代码和产业链关系是研究框架，不代表所有公司都纯粹受益，也不代表资源倍数会线性传导为收入增速或股价涨幅。正式投资研究仍需补充公司公告、财报、订单、客户集中度、库存、毛利率和现金流验证。

页面内的公开资料链接优先指向企业官网、投资者关系页面或研究论文，便于继续核验。
